## A와 B 독립 판정

**A 미해결.** `naver-provider.mjs:118–134,173–181,450–498`의 alias는 여전히 단위별 변환·분모 metadata가 없다. 보정은 현재 누적량/과거 종일 평균이며 동시간 거래량 비교가 아니다. 검증 가능한 quote session이 없으면 보정을 건너뛴다.

**수정 PR 반영 후 보고서·관심종목 조회 중심의 개인용 APK 베타는 조건부 진행 가능하다.** 다중 사용자 인증으로 바꾸거나 서버 DB를 교체해야만 개인 베타를 시작할 수 있다는 뜻은 아니다. 다만 A/B는 여전히 '신뢰할 수 있는 한국·미국 전체시장 급등 알림'을 완료했다고 판정하는 데 차단 사항이다. 해당 기능은 실험적 후보 감시로만 이해해야 한다.

실기기/Railway에서는 APK 설치·HTTPS 주소/키, FCM token→ticket→receipt→실제 표시, foreground/background/cold-start와 연속 알림 탭, PDF viewer, Volume mount·재배포 데이터 유지·백업 복원,1 replica/1 Node process, 장중 실제 시세 세션 및24시간 요청/자원 비용을 확인한다. 앱 키는 APK에 들어가므로 비공유 개인 설치를 유지하고 publisher/OpenAI 키는 앱에 넣지 않는다.
